Welcome to htmlang

A small layout language that compiles to one static HTML file . Structure starts with @ , everything else is content.

1.

Layout

@el stacks its children in a column and @row lays them out side by side. spacing is the gap between children. flex-direction row makes any column a row, also from a width up ( md:flex-direction row ), and the children's width fill follows it.

2.

Text

Lines without an @ are text. Braces put elements inside a line: bold , italic , important , H 2 O, highlighted , a link , and Ctrl+K .

A backslash escapes: @ at the start of a line, $price, and {braces}.

Style

Besides the layout attributes, every attribute is a CSS property with its CSS name and value. A bare number is pixels for lengths, and \, keeps a comma in a value.

4.

Functions

Functions are @let @name with a body. Their parameters are listed and passed like attributes, a name alone passes true, and a body can be text like this one.

A call works wherever an element does, even inside a sentence: press Ctrl K to search.

7.

HTML

Every other element has its HTML name, and HTML attributes are written key=value . @page is the root element: its styles go on <body> , a column that fills the window, and its key=value attributes on <html> , like this page's lang=en .

What does this compile to?

Flexbox and grid CSS in one <style> , and no JavaScript.
